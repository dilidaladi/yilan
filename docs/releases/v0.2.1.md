这是 `dilidaladi/yilan` fork 的维护版本，基于原项目的一览 v0.2.0。

- 移到废纸篓前核对文件身份。若目标已被同名文件替换，操作会停止并提示重新打开。
- 撤销时遇到同名文件，不会覆盖该文件，也会保留撤销记录。移开冲突文件后可按 ⌘Z 重试。

适用于 macOS 26 或更高版本，同时支持 Apple 芯片与 Intel。下载并解压 `Yilan-0.2.1.zip` 后，将 `Yilan.app` 拖入「应用程序」。本版本仍为临时签名，未经过 Apple 公证；如被拦截，可在「系统设置 → 隐私与安全性」选择「仍要打开」。

下载 ZIP 和校验文件后，可检查完整性，并验证包来自本 fork 的 GitHub Actions 构建：

```sh
shasum -a 256 -c Yilan-0.2.1.zip.sha256
gh attestation verify Yilan-0.2.1.zip -R dilidaladi/yilan
```

---

This maintenance release of the fork is based on upstream Yilan v0.2.0. Yilan now checks the target before moving it to the Trash and keeps the undo entry if the original path is occupied. Once the conflicting file is moved aside, press ⌘Z to retry.

Requires macOS 26 or later. The ZIP contains a universal app for Apple silicon and Intel. It is ad-hoc signed and has not been notarized by Apple.
