这是 `dilidaladi/yilan` fork 的维护版本，选择性借鉴了上游 v0.3.0 的轻编辑和浏览交互。

- 按 `E` 或点击顶部裁切图标，可裁切、旋转和调整静态图片尺寸。导出 PNG 或 JPEG 副本，同名自动编号，原图不变。
- 顶部缩放菜单可选适应窗口、实际大小及常用放大比例。原有 `0`、`1` 快捷键继续可用。
- 双击标题栏空白处会按 macOS 设置处理窗口。

轻编辑用于受支持的单张静态图片，最多 4800 万像素、单边 16384 像素。副本保存在原文件旁，不携带原图的 EXIF 信息。这个版本不包含评星。

适用于 macOS 26 及以上，支持 Apple 芯片及 Intel。安装包从本 fork 的 `v0.3.1` 标签在本机构建，使用临时签名，未经过 Apple 公证。下载 ZIP 和校验文件到同一目录后，可执行：

```sh
shasum -a 256 -c Yilan-0.3.1.zip.sha256
```

---

Quick Edit (`E`) crops, rotates, and resizes supported still images and exports a new PNG or JPEG. The original and existing copies are preserved. The top zoom menu adds common presets, and double-clicking the blank title bar follows the macOS window setting. This fork release does not include star ratings.

Requires macOS 26 or later. The universal archive was built locally from the v0.3.1 tag. It is ad-hoc signed and has not been notarized by Apple.
