这是 `dilidaladi/yilan` fork 的维护版本。

- 同名文件被替换后，主图、缩略图、环境光和信息面板会刷新，即使大小和修改时间都没变。
- 打开不支持的文件时会给出提示，并保留正在看的图片。
- 缩略图采用原生按钮，可通过辅助功能工具直接选图。
- 最近使用的文件夹封面在后台读取文件属性，减少慢速磁盘或网络盘造成的界面卡顿。

适用于 macOS 26 或更高版本，支持 Apple 芯片及 Intel。下载并解压 `Yilan-0.2.2.zip` 后，将 `Yilan.app` 拖入「应用程序」。本包从 `v0.2.2` 标签在本机打出，使用临时签名，未经过 Apple 公证。下载 ZIP 和校验文件到同一目录后，可执行：

```sh
shasum -a 256 -c Yilan-0.2.2.zip.sha256
```

---

This maintenance release refreshes the viewer when a same-name file is replaced, keeps the current selection when an unsupported file is opened, makes thumbnails accessible as native buttons, and moves recent-folder cover metadata reads off the main thread.

Requires macOS 26 or later. The universal archive was built locally from the v0.2.2 tag. It is ad-hoc signed and has not been notarized by Apple.
